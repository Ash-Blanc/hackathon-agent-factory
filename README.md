# Autonomous Hackathon Agent Factory Loop

An end-to-end autonomous factory loop for:
1. Scanning high-prize online hackathons where AI assistance is permitted via **TinyFish**.
2. Gathering competitive intelligence, past winner trends, and inspirations (HN, Reddit, YC) via **Parallel.ai** and **Nia**.
3. Scaffolding, building, and testing applications inside cloud sandboxes using **OpenCode** or **Hermes**.
